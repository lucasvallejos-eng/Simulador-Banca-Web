Un proyecto académico desarrollado en el marco de la asignatura **Lenguaje de Programación 2**. Consiste en un simulador básico de home banking diseñado para gestionar las operaciones esenciales de una cuenta bancaria.

---

## 📌 Descripción General

El objetivo de este proyecto es modelar la lógica y el flujo funcional de un sistema de banca web tradicional, permitiendo a los usuarios autenticarse mediante credenciales de acceso y ejecutar operaciones transaccionales de forma segura dentro del entorno de prueba.

## ✨ Funcionalidades

Una vez que el usuario inicia sesión correctamente, el sistema ofrece acceso a los siguientes módulos:

* 🔐 **Autenticación:** Inicio de sesión y validación de credenciales (Nro. de cuenta y PIN de acceso).
* 💵 **Depósitos:** Registro e incremento de saldo en la cuenta.
* 💸 **Transferencias:** Envío de fondos a otras cuentas registradas mediante PIN transaccional.
* 📊 **Consulta de Saldo:** Visualización en tiempo real del dinero disponible.
* 👤 **Información Personal:** Módulo con los datos del titular de la cuenta y tarjeta asociada.
* 📜 **Historial de Transacciones:** Registro cronológico de movimientos financieros.
